# 每台新设备的私有检查表模板

复制此表到**仓库外**的设备私有目录填写，不在公开 fork 提交真实 IP、序列号、SSID或日志，更不填写密码、密钥、cookie。每项填写“通过/失败/未验证/不适用”和非敏感证据，不能默认全通过。

## 安装后验收

- [ ] 首次启动、屏幕、触摸、时间同步正常。
- [ ] 根文件系统容量符合预期，剩余磁盘足够。
- [ ] 新网络可扫描、选择、输入密码；不是复制旧机配置。
- [ ] 后台独立强密码，Ubuntu/root公开默认密码处理完成。
- [ ] 新设备SSH指纹独立；如采用公钥专用管理，先验证登录/sudo再关闭密码入口。
- [ ] 客户端设备身份独立，未恢复其它机器的userdata或主机私钥。
- [ ] 基础服务active，health正确；注明仅为状态检查。
- [ ] 实体麦克风开关有效，喊“小麦小麦”真实回应。
- [ ] 说“你好”有识别文字、回答文字和实际晓晓语音；记录等待时间。
- [ ] 问“北京明天天气怎么样”实际调用天气工具并播出有日期的具体数据。
- [ ] 问一条新闻实际调用工具并播出；不只凭模型自述通过。
- [ ] 底栏Wi-Fi、后退、刷新、语音助手可点；返回主页正常。
- [ ] 未安装的媒体入口不显示；选装媒体时只能启动一个原生媒体实例。
- [ ] 洛雪首次配置和全屏、128k单曲实际出声、暂停/切歌/关闭返回通过；没有把排行榜显示当播放通过。
- [ ] B站实际画面/声音、暂停/拖动、关闭返回通过；记录冷启动/起播时间。
- [ ] 换到另一个经许可网络后重新找IP，语音、天气/新闻和选装媒体复验。
- [ ] 经所有者同意正常关机、重启后配置保留且基本功能复验。
- [ ] 无固定家庭代理/虚拟机的必需依赖；没有公网暴露管理后台。
- [ ] 本机备份/逐层回退路径已核对，未删除唯一原厂备份。
